# Skills shop

A Snowflake Native App: a shop of **skills** (instruction folders for Snowflake's managed coding agent) and a chat with one chosen skill.

Open the application, pick a skill, read what it does, and choose **Chat with this skill**. The agent runs in Snowflake's sandbox, as this application, and asks you before it runs a command.

The skills are published by the application's developers; you cannot change them from here.
