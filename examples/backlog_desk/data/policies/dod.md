# Definition of Done

A ticket is **done** only when all of the following are true:

1. **Acceptance criteria** in the ticket description are met.
2. **Tests** — unit or checklist coverage noted in the description (or linked).
3. **Docs** — user-facing change has a release-notes bullet or README touch.
4. **No open blockers** — status is not `blocked`; dependencies resolved.
5. **Review** — owner is not `unassigned`; another teammate has reviewed (note in description).
6. **Points** — story points set (> 0) for feature/bug work.
