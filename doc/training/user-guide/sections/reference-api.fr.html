L'API Python publique de streamlit-coco, telle qu'exportée depuis streamlit_coco (voir l'index pour la version exacte que décrit ce guide). Les modules privés (bridge, tool_cards, tool_extract, et d'autres non listés ici) sont des détails d'implémentation, pas une API stable — ils ne sont pas documentés comme entrées de référence.

CocoOptions#

Le dataclass de configuration pour une session ou un appel query() (streamlit_coco/options.py).

ChampTypeValeur par défautEffet
connection`str \None`NoneNom de la connexion CLI Snowflake à utiliser
cwdstr"."Répertoire de travail dans lequel opèrent les outils de l'agent
model`str \None`NoneSélection du modèle ; préférez "auto" si défini
allowed_toolslist[str][]Outils pouvant s'exécuter sans approbation
disallowed_toolslist[str][]Outils entièrement bloqués
permission_modestr"default"Mode de permission global, ex. "plan" pour les flux ExitPlanMode
profile`str \None`NoneNom du profil SDK
cli_path`str \None`NoneSurcharge le chemin de la CLI cortex (la variable d'environnement CORTEX_CODE_CLI_PATH fonctionne aussi)
mcp_serversdict{}Configuration des serveurs MCP transmise au SDK
hooksdict{}Passthrough des hooks SDK
require_approval_for`list[str] \Callable`[]Outils qui se mettent en pause pour approbation humaine ; AskUserQuestion/ExitPlanMode se mettent toujours en pause
output_schema`dict \None`NoneJSON Schema transmis au SDK sous forme de output_format ($schema/$id retirés avant transmission)
max_turns`int \None`NonePlafonne le nombre de tours de l'agent
approval_timeout_secondsfloat600.0Secondes d'attente d'une approbation en attente avant ApprovalTimeoutError
extra_sdk_optionsdict{}Kwargs de passthrough transmis à l'objet options natif du SDK

Méthodes#

  • options_hash() -> str — un hash stable des options qui ne change que

    lorsqu'une valeur affectant la session en cours change (utilisé pour décider si le worker en arrière-plan doit redémarrer).

  • to_sdk_options(*, can_use_tool=None) — construit l'objet options natif

    du SDK ; lève SDKNotInstalledError si le SDK n'est pas installé.

  • auto_allow_tools() -> list[str] — l'ensemble effectif des outils qui

    s'exécutent sans approbation.

  • tools_requiring_approval() -> list[str] — l'ensemble effectif des

    outils qui se mettent en pause pour approbation.

python
options = st_coco.CocoOptions(
    connection="my_connection",
    cwd=".",
    allowed_tools=["Read", "Glob", "Grep"],
    require_approval_for=["Edit", "Write", "Bash"],
    approval_timeout_seconds=300.0,
)

CocoRunStatus#

Une énumération str (streamlit_coco/session.py) donnant l'état courant d'une session.

ValeurSignification
idleAucune activité de session démarrée pour l'instant
connectingLe worker en arrière-plan démarre
readyConnecté, en attente d'un prompt
runningUn tour est en cours
awaiting_userUn appel d'outil est en pause en attente d'approbation
completedLe tour s'est terminé normalement
errorLe tour ou la session a échoué
cancelledLe tour a été annulé
python
if session.chat_result().status == st_coco.CocoRunStatus.awaiting_user:
    st.warning("Waiting on an approval.")

CocoSession#

Une session multi-tours adossée à un CortexCodeSDKClient sur un thread en arrière-plan (streamlit_coco/session.py).

MembreEffet
send(prompt)Met un prompt en file d'attente ; lève SessionStartError/SessionNotReadyError si non prête
start()Démarre le worker en arrière-plan
ensure_ready(timeout=120)Attend que la session soit prête ; lève SessionNotReadyError en cas de délai dépassé ou d'échec de démarrage
run(prompt, *, timeout=None)Envoie un prompt et attend son résultat
stream()Itère de façon asynchrone les événements du tour courant/suivant
set_permission_mode(mode)Change le mode de permission
execute_plan(...)Exécute un plan produit sous permission_mode="plan"
cancel()Annule le tour en cours
close()Arrête le worker en arrière-plan
reset()Efface l'historique de conversation et redémarre le worker
chat_result()Retourne le CocoChatResult courant
is_running / is_ready / is_connecting / needs_pollingPropriétés d'état booléennes
transcript / messages / eventsL'historique accumulé des tours/événements
last_error / init_info / structured_outputDiagnostics et la dernière charge utile structurée
permission_managerLe gestionnaire d'état d'approbation de la session
add_event_listener(cb)Enregistre un callback invoqué pour chaque nouvel événement
sync_options(options)Applique un nouveau CocoOptions ; redémarre le worker si options_hash() a changé
set_show_structured_inline(bool)Bascule le rendu en ligne de la sortie structurée
python
session = st_coco.CocoSession(options=options, key="copilot")
session.start()
result = await session.run("List the tables in my schema.")
