The public Python API of streamlit-coco, as exported from streamlit_coco (see the index for the exact version this guide describes). Private modules (bridge, tool_cards, tool_extract, and others not listed here) are implementation details, not stable API — they are not documented as reference entries.

CocoOptions#

The configuration dataclass for a session or a query() call (streamlit_coco/options.py).

FieldTypeDefaultEffect
connection`str \None`NoneSnowflake CLI connection name to use
cwdstr"."Working directory the agent's tools operate in
model`str \None`NoneModel selection; prefer "auto" when set
allowed_toolslist[str][]Tools that may run without approval
disallowed_toolslist[str][]Tools blocked entirely
permission_modestr"default"Overall permission mode, e.g. "plan" for ExitPlanMode flows
profile`str \None`NoneSDK profile name
cli_path`str \None`NoneOverride the cortex CLI path (CORTEX_CODE_CLI_PATH env also works)
mcp_serversdict{}MCP server configuration forwarded to the SDK
hooksdict{}SDK hooks passthrough
require_approval_for`list[str] \Callable`[]Tools that pause for human approval; AskUserQuestion/ExitPlanMode always pause
output_schema`dict \None`NoneJSON Schema forwarded to the SDK as output_format ($schema/$id stripped before forwarding)
max_turns`int \None`NoneCaps the number of agent turns
approval_timeout_secondsfloat600.0Seconds to wait for a pending approval before ApprovalTimeoutError
extra_sdk_optionsdict{}Passthrough kwargs forwarded to the SDK's own options object

Methods#

  • options_hash() -> str — a stable hash of the options that changes only

    when a value affecting the running session changes (used to decide whether the background worker must restart).

  • to_sdk_options(*, can_use_tool=None) — builds the SDK-native options

    object; raises SDKNotInstalledError if the SDK is not installed.

  • auto_allow_tools() -> list[str] — the effective set of tools that run

    without approval.

  • tools_requiring_approval() -> list[str] — the effective set of tools that

    pause for approval.

python
options = st_coco.CocoOptions(
    connection="my_connection",
    cwd=".",
    allowed_tools=["Read", "Glob", "Grep"],
    require_approval_for=["Edit", "Write", "Bash"],
    approval_timeout_seconds=300.0,
)

CocoRunStatus#

A str enum (streamlit_coco/session.py) giving a session's current state.

ValueMeaning
idleNo session activity started yet
connectingBackground worker starting
readyConnected, waiting for a prompt
runningA turn is in progress
awaiting_userA tool call is paused on a pending approval
completedThe turn finished normally
errorThe turn or the session failed
cancelledThe turn was cancelled
python
if session.chat_result().status == st_coco.CocoRunStatus.awaiting_user:
    st.warning("Waiting on an approval.")

FieldTypeDefaultEffect
last_prompt`str \None`—The most recent prompt sent
last_result`CocoEvent \None`—The most recent terminal event
pending_approval`dict \None`—The pending approval request, if any
structured_outputAny—The last structured payload, if output_schema was set

result = session.chat_result()
if result.pending_approval:

CocoSession#

A multi-turn session backed by a CortexCodeSDKClient on a background thread (streamlit_coco/session.py).

MemberEffect
send(prompt)Queue a prompt; raises SessionStartError/SessionNotReadyError if not ready
start()Start the background worker
ensure_ready(timeout=120)Await readiness; raises SessionNotReadyError on timeout or boot failure
run(prompt, *, timeout=None)Send a prompt and await its result
stream()Async-iterate events for the current/next turn
set_permission_mode(mode)Change the permission mode
execute_plan(...)Execute a plan produced under permission_mode="plan"
cancel()Cancel the in-flight turn
close()Tear down the background worker
reset()Clear the transcript and restart the worker
chat_result()Return the current CocoChatResult
is_running / is_ready / is_connecting / needs_pollingBoolean state properties
transcript / messages / eventsThe accumulated turn/event history
last_error / init_info / structured_outputDiagnostics and the last structured payload
permission_managerThe session's approval-state manager
add_event_listener(cb)Register a callback invoked per new event
sync_options(options)Apply new CocoOptions; restarts the worker if options_hash() changed
set_show_structured_inline(bool)Toggle inline structured-output rendering

Upload helpers#

upload_to_cwd(target, files, *, subdir="_uploads", overwrite="error", max_bytes=DEFAULT_MAX_BYTES, allowed_extensions=DEFAULT_ALLOWED_EXTENSIONS) -> list[UploadedPath]#

Writes uploaded files into a session's, options', or path's working directory. target may be a path, a CocoOptions, or a CocoSession. Raises CwdUploadError on a bad filename (path-traversal guard), a disallowed extension, an oversize payload, or an overwrite conflict.

python
paths = st_coco.upload_to_cwd(session, files, overwrite="error")

Exception hierarchy (streamlit_coco/errors.py)#

ClassRaised whenMessage
