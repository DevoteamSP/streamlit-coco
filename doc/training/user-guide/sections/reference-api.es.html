CocoOptions#

El dataclass de configuración para una sesión o una llamada a query() (streamlit_coco/options.py).

CampoTipoPor defectoEfecto
connection`str \None`NoneNombre de la conexión del Snowflake CLI a usar
cwdstr"."Directorio de trabajo en el que operan las herramientas del agente
model`str \None`NoneSelección de modelo; preferir "auto" cuando se define
allowed_toolslist[str][]Herramientas que pueden ejecutarse sin aprobación
disallowed_toolslist[str][]Herramientas bloqueadas por completo
permission_modestr"default"Modo de permisos general, por ejemplo "plan" para flujos ExitPlanMode
profile`str \None`NoneNombre de perfil del SDK
cli_path`str \None`NoneAnula la ruta del CLI cortex (CORTEX_CODE_CLI_PATH también funciona)
mcp_serversdict{}Configuración de servidores MCP reenviada al SDK
hooksdict{}Passthrough de hooks del SDK
require_approval_for`list[str] \Callable`[]Herramientas que se pausan a la espera de aprobación humana; AskUserQuestion/ExitPlanMode siempre se pausan
output_schema`dict \None`NoneJSON Schema reenviado al SDK como output_format ($schema/$id eliminados antes del reenvío)
max_turns`int \None`NoneLimita el número de turnos del agente
approval_timeout_secondsfloat600.0Segundos a esperar por una aprobación pendiente antes de ApprovalTimeoutError
extra_sdk_optionsdict{}Kwargs de passthrough reenviados al propio objeto de opciones del SDK

Métodos#

  • options_hash() -> str — un hash estable de las opciones que cambia

    solo cuando cambia un valor que afecta a la sesión en ejecución (usado para decidir si el worker en segundo plano debe reiniciarse).

  • to_sdk_options(*, can_use_tool=None) — construye el objeto de opciones

    nativo del SDK; lanza SDKNotInstalledError si el SDK no está instalado.

  • auto_allow_tools() -> list[str] — el conjunto efectivo de herramientas

    que se ejecutan sin aprobación.

  • tools_requiring_approval() -> list[str] — el conjunto efectivo de

    herramientas que se pausan a la espera de aprobación.

python
options = st_coco.CocoOptions(
    connection="my_connection",
    cwd=".",
    allowed_tools=["Read", "Glob", "Grep"],
    require_approval_for=["Edit", "Write", "Bash"],
    approval_timeout_seconds=300.0,
)

CocoRunStatus#

Una enumeración str (streamlit_coco/session.py) que da el estado actual de una sesión.

ValorSignificado
idleNinguna actividad de sesión iniciada aún
connectingEl worker en segundo plano está arrancando
readyConectado, a la espera de un prompt
runningUn turno está en curso
awaiting_userUna llamada a herramienta está pausada a la espera de aprobación
completedEl turno terminó con normalidad
errorEl turno o la sesión fallaron
cancelledEl turno se canceló
python
if session.chat_result().status == st_coco.CocoRunStatus.awaiting_user:
    st.warning("Waiting on an approval.")

CocoChatResult#

Una instantánea en dataclass del resultado de un turno, devuelta por panel(), chat() y session.chat_result().

CampoTipoPor defectoEfecto
last_prompt`str \None`—El prompt más reciente enviado

structured_outputAny—El último payload estructurado, si se definió output_schema

    st.info(f"Waiting on: {result.pending_approval['tool_name']}")

CocoSession#

Una sesión de varios turnos respaldada por un CortexCodeSDKClient en un hilo en segundo plano (streamlit_coco/session.py).

MiembroEfecto
send(prompt)Encola un prompt; lanza SessionStartError/SessionNotReadyError si no está listo
start()Inicia el worker en segundo plano
ensure_ready(timeout=120)Espera a la disponibilidad; lanza SessionNotReadyError en timeout o fallo de arranque
run(prompt, *, timeout=None)Envía un prompt y espera su resultado
stream()Itera de forma asíncrona los eventos del turno actual/siguiente
set_permission_mode(mode)Cambia el modo de permisos
execute_plan(...)Ejecuta un plan producido bajo permission_mode="plan"
cancel()Cancela el turno en curso
close()Derriba el worker en segundo plano
reset()Limpia la transcripción y reinicia el worker
chat_result()Devuelve el CocoChatResult actual
is_running / is_ready / is_connecting / needs_pollingPropiedades booleanas de estado
transcript / messages / eventsEl historial acumulado de turnos/eventos
last_error / init_info / structured_outputDiagnósticos y el último payload estructurado
permission_managerEl gestor del estado de aprobación de la sesión
add_event_listener(cb)Registra un callback invocado por cada evento nuevo
sync_options(options)Aplica nuevas CocoOptions; reinicia el worker si options_hash() cambió
set_show_structured_inline(bool)Activa/desactiva el renderizado en línea de la salida estructurada
python
session = st_coco.CocoSession(options=options, key="copilot")
session.start()
result = await session.run("List the tables in my schema.")

Helpers de subida#

upload_to_cwd(target, files, *, subdir="_uploads", overwrite="error", max_bytes=DEFAULT_MAX_BYTES, allowed_extensions=DEFAULT_ALLOWED_EXTENSIONS) -> list[UploadedPath]#

paths = st_coco.upload_to_cwd(session, files, overwrite="error")
