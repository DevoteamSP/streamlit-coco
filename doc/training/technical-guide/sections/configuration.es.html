Cada superficie de configuración que expone streamlit-coco: los campos de CocoOptions, las variables de entorno, y el archivo de conexiones de Snowflake que lee.

Campos de CocoOptions#

CocoOptions (streamlit_coco/options.py) es un dataclass. Todos los campos son definibles por palabra clave; no hay ningún archivo de configuración para la librería en sí — una app construye una instancia de CocoOptions en código.

Dos métodos que vale la pena conocer al configurar una sesión:

  • options_hash() — un hash estable sobre los campos que afectan a los

    permisos de herramienta. CocoSession reinicia su worker en segundo plano solo cuando este hash cambia entre llamadas (ver architecture).

  • to_sdk_options(*, can_use_tool=None) — construye el

    CortexCodeAgentOptions del SDK; lanza SDKNotInstalledError si cortex-code-agent-sdk no está instalado.

Archivo de conexión de Snowflake#

CoCo se autentica a través del propio archivo de conexión del Snowflake CLI, nunca mediante configuración de la librería:

  • Ubicación por defecto: ~/.snowflake/connections.toml.
  • El ~/.snowflake/config.toml heredado también se detecta (sus

    perfiles viven bajo una tabla [connections] de nivel superior en lugar de entradas [connections.<name>] en la raíz).

  • Resolución de toml_file (usada por check_environment, el selector

    Config file de copilot_rail, y list_snowflake_connections):

    • un nombre de archivo simple se resuelve bajo ~/.snowflake/; una

      ruta se usa tal cual.

    • si se omite: cuando existe exactamente un archivo *.toml bajo

      ~/.snowflake/, se usa ese archivo sin importar su nombre; con varios archivos presentes, connections.toml gana, luego config.toml, luego el resto de archivos alfabéticamente.

Ejemplo de entrada de conexión:

toml
[connections.analytics]
account = "xy12345"
user = "you@company.com"
authenticator = "externalbrowser"

Helpers relacionados: list_snowflake_toml_files(), list_snowflake_connections(toml_file=None), resolve_snowflake_config_path(toml_file=None, *, must_exist=True), default_snowflake_connection_name(toml_file=None). Todos viven en streamlit_coco/diagnostics.py y son ejercitados por check_environment() / require_environment() — ver install para el flujo de verificación y help.html#snowflake-config-not-found cuando falla la sonda.
