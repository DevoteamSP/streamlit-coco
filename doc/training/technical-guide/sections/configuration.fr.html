Chaque surface de configuration exposée par streamlit-coco : les champs CocoOptions, les variables d'environnement, et le fichier de connexions Snowflake qu'elle lit.

Champs CocoOptions#

CocoOptions (streamlit_coco/options.py) est une dataclass. Tous les champs sont paramétrables par mot-clé ; il n'existe pas de fichier de configuration pour la bibliothèque elle-même — une application construit une instance CocoOptions en code.

NomTypeDéfautEffetExemple

cwdstr"."Répertoire de travail dans lequel opèrent les outils de l'agent (Read/Write/Bash/…).CocoOptions(cwd="./workspace")

Deux méthodes à connaître lors de la configuration d'une session :

  • options_hash() — un hash stable sur les champs qui affectent les

    permissions d'outils. CocoSession ne redémarre son worker en arrière-plan que lorsque ce hash change entre deux appels (voir architecture).

  • to_sdk_options(*, can_use_tool=None) — construit le

    CortexCodeAgentOptions du SDK ; lève SDKNotInstalledError si cortex-code-agent-sdk n'est pas installé.

Fichier de connexions Snowflake#

CoCo s'authentifie via le propre fichier de connexions du Snowflake CLI, jamais via la configuration de la bibliothèque :

  • Emplacement par défaut : ~/.snowflake/connections.toml.
  • L'ancien ~/.snowflake/config.toml est aussi détecté (ses profils vivent

    sous une table [connections] de premier niveau plutôt que des entrées [connections.<name>] à la racine).

  • Résolution de toml_file (utilisée par check_environment, le

    sélecteur de fichier de configuration de copilot_rail, et list_snowflake_connections) :

    • un simple nom de fichier est résolu sous ~/.snowflake/ ; un chemin

      est utilisé tel quel.

    • s'il est omis : quand exactement un fichier *.toml existe sous

      ~/.snowflake/, ce fichier est utilisé quel que soit son nom ; avec plusieurs fichiers présents, connections.toml l'emporte, puis config.toml, puis les fichiers restants par ordre alphabétique.

Exemple d'entrée de connexion :

toml
[connections.analytics]
account = "xy12345"
user = "you@company.com"
authenticator = "externalbrowser"

Aides associées : list_snowflake_toml_files(), list_snowflake_connections(toml_file=None), resolve_snowflake_config_path(toml_file=None, *, must_exist=True), default_snowflake_connection_name(toml_file=None). Toutes vivent dans streamlit_coco/diagnostics.py et sont exercées par check_environment() / require_environment() — voir install pour le flux de vérification et help.html#snowflake-config-not-found quand la sonde échoue.
