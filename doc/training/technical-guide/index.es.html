Esta guía describe streamlit-coco 0.1.9.

streamlit-coco es una librería Python/Streamlit que incrusta el Cortex Code Agent SDK de Snowflake ("CoCo") en una app Streamlit: un Copilot en rail lateral o en panel completo, puertas de aprobación human-in-the-loop para herramientas destructivas, una vista previa en vivo de una app que CoCo acaba de escribir, salida estructurada hacia tus propios widgets, y una API headless query() / CocoSession para scripts y CI. El estado del paquete es alpha (Development Status :: 3 - Alpha).

Esta guía es para quienes ejecutan, mantienen y extienden streamlit-coco en sí — no para alguien que construye una app Streamlit sobre ella (ese lector quiere la Guía de usuario).

Contenidos#

Entender

  • architecture — componentes, mapa del repositorio, flujo de datos, invariantes
  • data-and-contracts — CocoEvent, contratos JSON Schema, artefactos de salida, versionado
  • limits — limitaciones conocidas, expuestas con claridad

Ejecutar

  • install — prerrequisitos y pasos de instalación ordenados, solo objetivo local
  • configuration — cada campo de CocoOptions, variable de entorno, y archivo de configuración
  • operations — ejecutar, programar, monitorizar, coste/latencia, limpieza
  • security — roles y grants, secretos, modelo de amenazas, postura de seguridad de CI

Construir

  • testing-and-ci — árbol de tests, puertas, qué comprueba CI
  • extending — renderizador de texto, despacho de familia de herramienta, types de App Builder, nuevas apps de ejemplo
  • upgrade-and-release — versionado, el proceso de publicación, desinstalación

Respuestas

  • help — resolución de problemas indexada por síntoma

No cubierto#

  • Módulo de Skills — no hay .cortex/skills/*/SKILL.md en la raíz del repositorio. Los propios archivos types/*/SKILL.md de App Builder son skills de orientación de CoCo internas al ejemplo, documentadas en extending en lugar de un capítulo estilo reference-skills.
  • Objetos de Snowflake — la librería no crea ni posee ningún DDL de Snowflake. Toda la ejecución SQL ocurre a través de la propia herramienta SQL del agente, protegida por aprobación, usando lo que el rol conectado pueda hacer; no hay capítulo reference-procedures.
  • Native App — no hay manifest.yml / snowflake.yml en este repositorio. No está lanzado.
  • Modos de despliegue — solo se lanza hoy un objetivo: local (Streamlit, el CLI de CoCo, y la configuración de Snowflake en el mismo host). Streamlit in Snowflake (SiS) y SPCS son solo alcance del modelo de amenazas y de la hoja de ruta; no están implementados, así que install tiene un solo objetivo, no un capítulo modes.
  • Catálogo de controles — no hay archivos de reglas ni rúbrica de puntuación en este repositorio.
  • Infraestructura como código — no hay archivos *.tf en este repositorio.
