INTRODUCTION · 1 OF 3

What is streamlit-coco?

A Python/Streamlit library, not a hosted service
devoteam
Snowflake Partner
A PyPI package that embeds Snowflake's Cortex Code Agent SDK ("CoCo") into a Streamlit app: a right-rail or full-panel Copilot, human-in-the-loop approval gates for destructive tools, a live preview of an app CoCo just wrote, structured output into your own widgets, and a headless query() / CocoSession API for scripts and CI.
PACKAGE
streamlit-coco
VERSION
0.1.9 · alpha
REQUIRES
Python 3.10+ · Streamlit 1.53+

INTRODUCTION · 2 OF 3

The problem it solves

Everything you would otherwise build by hand
devoteam
Snowflake Partner
WITHOUT streamlit-coco
Session state that survives Streamlit reruns, streaming render of the agent transcript, readable tool cards instead of raw JSON dumps, and an approval flow for anything the agent could write, edit, or execute — all built from scratch.
WITH streamlit-coco
That plumbing as composable functions — panel(), chat_input_bar(), copilot_rail(), render_approvals() — so an app author writes the page and the options, not the session bridge.

make chat — the preferred pattern

You own the page, CoCo owns the session
devoteam
Snowflake Partner
Start gate first
check_environment() rendered by render_start_gate() — no agent starts until you click Start.
Streaming transcript
The @st.fragment poll loop (run_every=0.25) renders progressively — the rest of the page never reruns.
Tool cards, not JSON
A Glob/SQL card appears — the readable card the library builds instead of a raw dump.
Approval banner
Ask it to write something — Approve once · Always allow · Deny fires via render_approvals().

GUIDED TOUR · 2 OF 2

The rail — a column, not a page

make backlog and make bi-semantic
devoteam
Snowflake Partner
make backlog
Product Backlog Desk — Board / Epic / Ticket / Release. Copilot is not a nav page: it opens from the header Copilot button or an action link, closes with Close.
make bi-semantic
The fullest use of copilot_rail(). Title row: Copilot, Connection popover, icon-only Display config — two sliders, Last messages (default 8) and First n characters (default 200).
WHAT TO NOTICE ACROSS ALL THREE APPS
The agent always runs server-side. Approval gates are the same primitive everywhere. panel() is the common core; copilot_rail() adds connection chrome, job queuing, and transcript-compactness controls.

DEMO SCRIPT · IF THEY ASK

Questions you'll definitely get

Have these answers ready before you present
devoteam
Snowflake Partner
"Does it work with Streamlit in Snowflake?"
Not shipped today — local (CLI + Streamlit + Snowflake config on one host) is the only shipped topology; SiS/SPCS are threat-model scope only.
"Is it production-ready?"
Alpha (0.1.9) — the API may still move.
"Can I customize which tools need approval?"
Yes — allowed_tools / require_approval_for in CocoOptions, per tool.
"Is there an audit log of approvals?"
Not persisted today — "Always allow" is session-scoped only and clears on reset (tracked as SEC-01).
