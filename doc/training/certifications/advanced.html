Questions#

Q1Multiple choice

What did the 0.1.8 fix change about App Builder's Studio page?#

Answer

A — CHANGELOG 0.1.8 Fixed: Save & regenerate now writes BRIEF.md before queuing CoCo, closing the overwrite race.

Q2Multiple choice

What did the 0.1.7 fix change about make audit / CI pip-audit?#

Answer

B — CHANGELOG 0.1.7 Fixed: --skip-editable avoids a false "not found on PyPI" audit failure after a version bump.

Q3Multiple choice

Which two things did the 0.1.6 fix address?#

Answer

B — CHANGELOG 0.1.6 Fixed covers both the $schema/$id stripping and the use_container_width → width="stretch" change.

Q4Multiple choice

Which JSON Schema error did the 0.1.6 fix specifically avoid?#

Answer

A — The exact error text cited in 0.1.6's Fixed entry is the draft-URI schema-ref rejection.

Q5Multiple choice

What changed in the 0.1.5 security workflow?#

Answer

B — CHANGELOG 0.1.5 Changed (Security): CodeQL dropped (GHAS license gap), Gitleaks and pip-audit kept.

Q6Multiple choice

What did the 0.1.0 fix change about completed Grep/Glob tool cards?#

Answer

A — CHANGELOG 0.1.0 Fixed: Grep/Glob completed cards show a compact summary instead of a full dump.

Q7Multiple choice

A session raises SDKNotInstalledError. What does this indicate, and what is the fix?#

Answer

B — SDKNotInstalledError means the optional SDK extra is missing; the fix is pip install streamlit-coco[sdk] or make install.

Q8Multiple choice

A session raises CLIProbeError. What does this mean?#

Answer

B — CLIProbeError is specifically "binary found but --version failed," distinct from CLINotFoundError.

Q9Multiple choice

A session is stuck on "Starting CoCo…" with no further progress. What is the recommended first diagnostic step?#

Answer

B — The troubleshooting table's fix for a stuck connect is checking terminal logs and enabling STREAMLIT_COCO_DEBUG=1.

Q10Multiple choice

The chat input stays disabled right after the app boots. What is the likely cause and fix?#

Answer

A — Input disabled after boot maps to SessionNotReadyError/error status; fix the environment and reset from the sidebar.

Q11Multiple choice

What is the default overwrite behavior of upload_to_cwd(), and how does it differ from chat_input_bar()'s upload default?#

Answer

B — upload_to_cwd()'s own default is overwrite="error"; chat_input_bar() sets its upload_overwrite default to "replace".

Q12Multiple choice

What does app_viewer()'s log parser look for to detect an error, and what is a known limitation?#

Answer

A — The parser matches on those two strings; a later timestamped line can be misread as clearing the error.

Q13Multiple choice

Why can't app_viewer()'s host app read the previewed app's DOM traceback directly?#

Answer

A — The child preview is another origin (different port), so only the scraped log — not the DOM — is available to "Fix with CoCo."

Q14Multiple choice

When does ApprovalTimeoutError fire?#

Answer

B — ApprovalTimeoutError fires once approval_timeout_seconds (default 600s) elapses with no decision.

Q15Multiple choice

Is "Always allow" ever persisted across a Streamlit process restart?#

Answer

B — "Always allow" lives only in PermissionManager.always_allowed_tools in memory; it clears on reset(), close(), or restart.

Q16Multiple choice

What does the CORTEX_CODE_CLI_PATH environment variable override?#

Answer

B — CORTEX_CODE_CLI_PATH overrides the CLI path lookup when the CLI is not on PATH and cli_path was not passed.

Q17Multiple choice

Which values does is_debug_mode() treat as truthy for STREAMLIT_COCO_DEBUG / COCO_DEBUG?#

Answer

B — is_debug_mode()'s documented truthy set is "1"/"true"/"yes"/"on" (case-insensitive) or a truthy session-state flag.

Q18Multiple choice

Where is TTS_DATA_MODE read, and what does it affect?#

Answer

B — TTS_DATA_MODE is read only inside the bi_to_semantic child preview process, via app_viewer(env=...).

Q19Multiple choice

What is the status of security finding SEC-01?#

Answer

B — SEC-01 is listed open, target v0.2, in threat-model.md §7.

Q20Multiple choice

What is the status of SEC-02?#

Answer

B — SEC-02 is listed open, target v0.2; the security page's current guidance is interim, not the tracked deliverable.

Q21Multiple choice

What is the current status of CodeQL in this repository's CI?#

Answer

B — 0.1.5 dropped the CodeQL job for license reasons; security.yml today runs only Gitleaks and pip-audit.

Q22Multiple choice

Which two scanners actually run in security.yml today, and on what triggers?#

Answer

B — Gitleaks (CLI) and pip-audit --skip-editable run on PR, push-to-main, and the weekly Monday schedule.

Q23multiple choice select all

Which security items are OPEN (not resolved) per the threat model?#

Answer

A, B — A, B

Q24Multiple choice

Per the manual review in findings-report.md (version audited 0.1.0), which of these did the review NOT find in the source?#

Answer

A — The manual review explicitly states no shell=True, no hardcoded credentials, and no eval()/exec() were found.

Q25Multiple choice

What triggers a CocoSession's background worker to restart?#

Answer

B — options_hash() hashes only the tool-permission-affecting fields; CocoSession restarts its worker only when that hash changes.

Q26Multiple choice

What does wrap_exception() do?#

Answer

B — wrap_exception() message-sniffs the raw exception and uses context= to pick the right CocoError subclass.

Q27Multiple choice

What does ApprovalTimeoutError also subclass, alongside CocoError?#

Answer

B — ApprovalTimeoutError is documented as also a TimeoutError.

Q28Multiple choice

What does SDKNotInstalledError also subclass, alongside CocoError?#

Answer

A — SDKNotInstalledError is documented as also an ImportError.

Q29Multiple choice

What does the CI workflow ci.yml run on every PR to main?#

Answer

A — CI runs unit and e2e tests on every PR to main, without a live CoCo agent; live checks are manual-only.

Q30Multiple choice

Why might make audit have failed spuriously right after a version bump, before the 0.1.7 fix?#

Answer

A — Before 0.1.7, pip-audit without --skip-editable reported the just-bumped local version as missing from PyPI.
