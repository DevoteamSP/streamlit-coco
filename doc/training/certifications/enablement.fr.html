Q1Multiple choice

Quel problème streamlit-coco résout-il pour l'auteur d'une application Streamlit ?#

Answer

B — La librairie fournit l'état de session, le streaming de l'historique de conversation, les cartes d'outils et la plomberie d'approbation sous forme de fonctions composables, afin que l'auteur d'application écrive la page et les options, pas le pont vers la session.

Q2Multiple choice

Quel énoncé décrit le mieux panel() ?#

Answer

B — panel(session, kwargs) -> CocoChatResult est la primitive native de sortie historique/champ, avec approbations et un contrôle Stop.

Q3Multiple choice

Qu'ajoute copilot_rail() par rapport à panel() ?#

Answer

A — copilot_rail() compose panel() en un Copilot en rail latéral avec un sélecteur de connexion, des jobs en file d'attente, une configuration d'affichage de l'historique de conversation et des questions d'exemple.

Q4Multiple choice

Que fait app_viewer() ?#

Answer

B — app_viewer(app_dir, ...) lance un processus enfant streamlit run, l'intègre dans une iframe, et propose Fix with CoCo en analysant le journal de prévisualisation.

Q5Multiple choice

Quelle commande lance l'implémentation de référence officielle du pattern préféré (panel() + chat_input_bar()) ?#

Answer

B — Le Makefile associe chat à « Run examples/chat_app.py » ; demo, run-app et copilot ne sont pas des cibles du Makefile.

Q6Multiple choice

Quel ensemble de prérequis est exact pour démarrer le parcours Enablement ?#

Answer

A — Les prérequis sont Python 3.10+, un compte Snowflake avec Cortex Code activé, le CLI cortex sur PATH (ou CORTEX_CODE_CLI_PATH), et un connections.toml/config.toml fonctionnel — aucun entrepôt dédié, Docker ou manifeste Native App n'est requis.

Lesquels de ces éléments font partie du pipeline du pattern préféré démontré dans examples/chat_app.py ? (Choix multiple — sélectionnez toutes les réponses applicables)#

Answer

Q8Multiple choice

Quelle commande installe streamlit-coco pour quelqu'un qui a seulement besoin du package publié, et non d'un checkout du dépôt de développement ?#

Answer

A — Le chemin réservé au package publié uniquement est pip install "streamlit-coco[sdk]" ; make install cible un checkout de dépôt, et les deux autres commandes n'installent pas ce package.

Q9Multiple choice

Sous quelle licence streamlit-coco est-il publié ?#

Answer

B — streamlit-coco est publié sous licence Apache-2.0.

Q10Multiple choice

Quelle est la version actuelle du package et son statut de publication décrits par ce pack de formation ?#

Answer

B — Le pack décrit la version 0.1.9, indiquée comme alpha — l'API peut encore évoluer.
