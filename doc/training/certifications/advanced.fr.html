Q1Multiple choice

Qu'est-ce que le correctif 0.1.8 a changé concernant la page Studio de l'App Builder ?#

Answer

A — CHANGELOG 0.1.8 Fixed : Save & regenerate écrit désormais BRIEF.md avant de mettre CoCo en file d'attente, fermant la course à l'écrasement.

Q2Multiple choice

Qu'est-ce que le correctif 0.1.7 a changé concernant make audit / pip-audit en CI ?#

Answer

B — CHANGELOG 0.1.7 Fixed : --skip-editable évite un faux échec d'audit « not found on PyPI » après un bump de version.

Q3Multiple choice

Quelles deux choses le correctif 0.1.6 a-t-il traitées ?#

Answer

B — CHANGELOG 0.1.6 Fixed couvre à la fois le retrait de $schema/$id et le changement use_container_width → width="stretch".

Q4Multiple choice

Quelle erreur JSON Schema le correctif 0.1.6 a-t-il spécifiquement évitée ?#

Answer

A — Le texte d'erreur exact cité dans l'entrée Fixed de 0.1.6 est le rejet de la référence de schéma avec URI de draft.

Q5Multiple choice

Qu'est-ce qui a changé dans le workflow de sécurité 0.1.5 ?#

Answer

B — CHANGELOG 0.1.5 Changed (Security) : CodeQL retiré (manque de licence GHAS), Gitleaks et pip-audit conservés.

Q6Multiple choice

Qu'est-ce que le correctif 0.1.0 a changé concernant les cartes d'outils Grep/Glob terminées ?#

Answer

A — CHANGELOG 0.1.0 Fixed : les cartes Grep/Glob terminées affichent un résumé compact plutôt qu'un dump complet.

Q7Multiple choice

Une session lève SDKNotInstalledError. Qu'est-ce que cela indique, et quelle est la solution ?#

Answer

B — SDKNotInstalledError signifie que l'extra SDK optionnel est manquant ; la solution est pip install streamlit-coco[sdk] ou make install.

Q8Multiple choice

Une session lève CLIProbeError. Que signifie ceci ?#

Answer

B — CLIProbeError signifie spécifiquement « binaire trouvé mais --version a échoué », distinct de CLINotFoundError.

Q9Multiple choice

Une session reste bloquée sur « Starting CoCo… » sans autre progression. Quelle est l'étape de diagnostic initiale recommandée ?#

Answer

B — La solution du tableau de dépannage pour une connexion bloquée est de vérifier les journaux du terminal et d'activer STREAMLIT_COCO_DEBUG=1.

Q10Multiple choice

Le champ de saisie du chat reste désactivé juste après le démarrage de l'application. Quelle est la cause probable et la solution ?#

Answer

A — Une saisie désactivée après le démarrage correspond à SessionNotReadyError/un statut d'erreur ; corriger l'environnement et réinitialiser depuis la barre latérale.

Q11Multiple choice

Quel est le comportement overwrite par défaut de upload_to_cwd(), et en quoi diffère-t-il du défaut de téléversement de chat_input_bar() ?#

Answer

B — Le défaut propre de upload_to_cwd() est overwrite="error" ; chat_input_bar() fixe son défaut upload_overwrite à "replace".

Q12Multiple choice

Que recherche l'analyseur de journaux de app_viewer() pour détecter une erreur, et quelle en est une limitation connue ?#

Answer

A — L'analyseur détecte ces deux chaînes ; une ligne horodatée ultérieure peut être mal interprétée comme une résolution de l'erreur.

Q13Multiple choice

Pourquoi l'application hôte de app_viewer() ne peut-elle pas lire directement la traceback DOM de l'application prévisualisée ?#

Answer

A — La prévisualisation enfant est une autre origine (port différent), donc seul le journal analysé — pas le DOM — est disponible pour « Fix with CoCo ».

Q14Multiple choice

Quand ApprovalTimeoutError se déclenche-t-elle ?#

Answer

B — ApprovalTimeoutError se déclenche une fois approval_timeout_seconds (600 s par défaut) écoulé sans décision.

Q15Multiple choice

« Always allow » est-il jamais persisté à travers un redémarrage du processus Streamlit ?#

Answer

B — « Always allow » ne vit que dans PermissionManager.always_allowed_tools en mémoire ; il s'efface à reset(), close(), ou au redémarrage.

Q16Multiple choice

Que remplace la variable d'environnement CORTEX_CODE_CLI_PATH ?#

Answer

B — CORTEX_CODE_CLI_PATH remplace la recherche du chemin du CLI lorsque le CLI n'est pas sur PATH et que cli_path n'a pas été transmis.

Q17Multiple choice

Quelles valeurs is_debug_mode() considère-t-elle comme vraies pour STREAMLIT_COCO_DEBUG / COCO_DEBUG ?#

Answer

B — L'ensemble de valeurs vraies documenté de is_debug_mode() est "1"/"true"/"yes"/"on" (insensible à la casse) ou un indicateur d'état de session vrai.

Q18Multiple choice

Où TTS_DATA_MODE est-il lu, et qu'affecte-t-il ?#

Answer

B — TTS_DATA_MODE n'est lu qu'à l'intérieur du processus de prévisualisation enfant de bi_to_semantic, via app_viewer(env=...).

Q19Multiple choice

Quel est le statut du constat de sécurité SEC-01 ?#

Answer

B — SEC-01 est listé comme ouvert, cible v0.2, dans threat-model.md §7.

Q20Multiple choice

Quel est le statut de SEC-02 ?#

Answer

B — SEC-02 est listé comme ouvert, cible v0.2 ; le guidage actuel de la page de sécurité est intérimaire, pas le livrable suivi.

Q21Multiple choice

Quel est le statut actuel de CodeQL dans la CI de ce dépôt ?#

Answer

B — 0.1.5 a retiré le job CodeQL pour des raisons de licence ; security.yml n'exécute aujourd'hui que Gitleaks et pip-audit.

Q22Multiple choice

Quels deux scanners s'exécutent réellement dans security.yml aujourd'hui, et sur quels déclencheurs ?#

Answer

B — Gitleaks (CLI) et pip-audit --skip-editable s'exécutent sur PR, push vers main, et la planification hebdomadaire du lundi.

Q23Select all that apply

Quels éléments de sécurité sont OUVERTS (non résolus) selon le modèle de menace ? (Choix multiple — sélectionnez toutes les réponses applicables)#

Answer

A, B — A, B

Q24Multiple choice

Selon la revue manuelle dans findings-report.md (version auditée 0.1.0), lequel de ces éléments la revue n'a-t-elle PAS trouvé dans le code source ?#

Answer

A — La revue manuelle indique explicitement qu'aucun shell=True, aucun identifiant codé en dur, et aucun usage de eval()/exec() n'a été trouvé.

Q25Multiple choice

Qu'est-ce qui déclenche le redémarrage du worker en arrière-plan d'une CocoSession ?#

Answer

B — options_hash() ne hashe que les champs affectant les permissions d'outils ; CocoSession ne redémarre son worker que lorsque ce hash change.

Q26Multiple choice

Que fait wrap_exception() ?#

Answer

B — wrap_exception() détecte le message de l'exception brute et utilise context= pour choisir la bonne sous-classe CocoError.

Q27Multiple choice

Que sous-classe également ApprovalTimeoutError, en plus de CocoError ?#

Answer

B — ApprovalTimeoutError est documentée comme étant aussi une TimeoutError.

Q28Multiple choice

Que sous-classe également SDKNotInstalledError, en plus de CocoError ?#

Answer

A — SDKNotInstalledError est documentée comme étant aussi une ImportError.

Q29Multiple choice

Que le workflow CI ci.yml exécute-t-il sur chaque PR vers main ?#

Answer

A — La CI exécute les tests unitaires et e2e sur chaque PR vers main, sans agent CoCo réel ; les vérifications live sont manuelles uniquement.

Q30Multiple choice

Pourquoi make audit a-t-il pu échouer de manière fallacieuse juste après un bump de version, avant le correctif 0.1.7 ?#

Answer

A — Avant 0.1.7, pip-audit sans --skip-editable signalait la version locale tout juste bumpée comme absente de PyPI.
