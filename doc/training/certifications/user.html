Questions#

0/ 30auto-scored: 0 / 30 · pass 24/30
Q1Multiple choice

What is the recommended order of the three Training cases?#

Answer

B — The cases are numbered and progress 01-simple → 02-intermediate → 03-advanced, increasing in difficulty.

Q2Multiple choice

What distinguishes 01-simple from 02-intermediate?#

Answer

A — 01-simple is the fully guided, sample-data happy path; 02-intermediate uses the learner's own data with checkpoints instead of click-by-click steps.

Q3Multiple choice

What is the defining feature of 03-advanced?#

Answer

B — 03-advanced presents a real breakage (real incident or CHANGELOG "Fixed" entry) that the learner diagnoses without guided steps.

Q4Multiple choice

Which sequence of calls does examples/chat_app.py use to implement the preferred pattern?#

Answer

B — This is the exact call chain the preferred-pattern reference example uses.

Q5Multiple choice

What does panel() return?#

Answer

B — panel(session, kwargs) -> CocoChatResult.

Q6Multiple choice

In panel(), what does setting output_label=None do?#

Answer

B — output_label=None hides the bordered output container; the default label otherwise is "CoCo output".

Q7Multiple choice

Which panel() parameter switches between showing the running transcript and showing only the latest field-style output?#

Answer

A — output_mode toggles between "transcript" (default) and "field" rendering.

Q8Multiple choice

What does chat_input_bar(session, accept_file=True) enable?#

Answer

B — accept_file=True (or "multiple") turns on file attachment, which is saved via the upload helpers into the session's cwd.

Q9Multiple choice

Which of these is a real copilot_rail() parameter?#

Answer

A — example_questions is a documented copilot_rail() parameter; the other three are not part of its signature.

Q10Multiple choice

What is job= used for in copilot_rail()?#

Answer

B — job= takes a dict (prompt, label, status, expect_structured) that queues a prompt for the rail to send.

Q11Multiple choice

What does transcript_display_config() add to a rail-based UI?#

Answer

A — transcript_display_config() renders the display-settings popover with Last-messages/First-n-characters controls.

Q12Multiple choice

What must app_dir point to for app_viewer() to work correctly?#

Answer

B — app_viewer(app_dir, ...) requires a folder with streamlit_app.py (or the script_name override); it must never point at the host app's own directory.

Q13Multiple choice

What does the "Fix with CoCo" button in app_viewer() do by default?#

Answer

B — The Fix action calls on_fix with a prompt from default_fix_prompt(traceback, app_dir), normally queuing a CoCo job.

Q14Multiple choice

How many app_viewer() previews are meant to point at the same app_dir at once?#

Answer

B — The documented limitation is one preview per app_dir.

Q15Multiple choice

Which CocoOptions field controls how long the app waits for a human decision on a pending approval before raising an error?#

Answer

B — approval_timeout_seconds (default 600.0, i.e. 10 minutes) governs the HITL wait before ApprovalTimeoutError.

Q16Multiple choice

What is the default CocoOptions.permission_mode?#

Answer

C — CocoOptions.permission_mode defaults to "default"; "plan" is used explicitly for ExitPlanMode flows.

Q17Multiple choice

Which function probes the environment (SDK install, CLI reachability, Snowflake config) without starting an agent, and never raises?#

Answer

B — check_environment() is the non-raising probe; require_environment() raises typed errors instead.

Q18Multiple choice

If toml_file is not passed and there is exactly one *.toml file under ~/.snowflake/, what happens?#

Answer

B — When exactly one *.toml exists under ~/.snowflake/, it is used regardless of its filename.

Q19Multiple choice

With several *.toml files under ~/.snowflake/ and no toml_file given, what is the selection order?#

Answer

B — With multiple files, connections.toml wins first, then config.toml, then alphabetical order.

Q20Multiple choice

What does examples/structured_output.py demonstrate?#

Answer

A — structured_output.py shows output_schema + on_structured_output routing JSON into a widget instead of chat text.

Q21Multiple choice

What does examples/headless_pipeline.py demonstrate?#

Answer

B — headless_pipeline.py is pure async Python using query()/CocoSession, with no Streamlit import.

Q22Multiple choice

What kind of demo is examples/approval_gate.py?#

Answer

C — approval_gate.py demonstrates the legacy CCv2 chat() all-in-one component.

Q23Multiple choice

What is distinctive about examples/backlog_desk/, compared to the other example apps?#

Answer

A — backlog_desk is the first rail-based, no-SQL example, backed by local JSON files.

Q24Multiple choice

In examples/backlog_desk/, how is its Copilot opened?#

Answer

C — Its Copilot is opened from a header "Copilot" button or an action link and closed with "Close" — it is not a navigation page.

Q25Multiple choice

What kinds of source files does examples/bi_to_semantic/ read as input?#

Answer

B — bi_to_semantic reads Tableau .twb/.twbx and/or Power BI .pbix/.pbit workbooks.

Q26Multiple choice

Where do files uploaded via upload_to_cwd() / cwd_uploader() / chat_input_bar(accept_file=...) land by default?#

Answer

A — Upload helpers write into <CocoOptions.cwd>/_uploads/ by default (subdirectory name configurable).

Q27Multiple choice

What does the App Builder "Build" step write into examples/app_builder/out/<slug>/?#

Answer

B — The Build step writes brief.json, BRIEF.md, sketches/*, and streamlit_app.py into out/<slug>/.

Q28Multiple choice

Where does the release build's SBOM get published?#

Answer

B — The SBOM (CycloneDX) is attached to GitHub Release assets and is produced only in CI, on tag release.

Q29Multiple choice

What does render_approvals() present, and in what button order?#

Answer

B — render_approvals() orders its controls Approve once, Always allow, Deny.

Q30multiple choice select all

Which of these tool families never expose an "Always allow" option in the approval UI?#

Answer

A, B — A, B
