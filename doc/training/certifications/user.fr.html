Questions#

0/ 30auto-scored: 0 / 30 · pass 24/30
Q1Multiple choice

Quel est l'ordre recommandé des trois cas de la formation (Training) ?#

Answer

B — Les cas sont numérotés et progressent 01-simple → 02-intermediate → 03-advanced, en difficulté croissante.

Q2Multiple choice

Qu'est-ce qui distingue 01-simple de 02-intermediate ?#

Answer

A — 01-simple est le chemin heureux entièrement guidé, avec données d'exemple ; 02-intermediate utilise les données propres de l'apprenant, avec des points de contrôle plutôt que des étapes pas à pas.

Q3Multiple choice

Quelle est la caractéristique déterminante de 03-advanced ?#

Answer

B — 03-advanced présente une véritable casse (incident réel ou entrée « Fixed » du CHANGELOG) que l'apprenant diagnostique sans étapes guidées.

Q4Multiple choice

Quelle séquence d'appels examples/chat_app.py utilise-t-il pour implémenter le pattern préféré ?#

Answer

B — C'est exactement la chaîne d'appels que l'exemple de référence du pattern préféré utilise.

Q5Multiple choice

Que retourne panel() ?#

Answer

B — panel(session, kwargs) -> CocoChatResult.

Q6Multiple choice

Dans panel(), que fait le fait de définir output_label=None ?#

Answer

B — output_label=None masque le conteneur bordé de la sortie ; le libellé par défaut est sinon « CoCo output ».

Q7Multiple choice

Quel paramètre de panel() bascule entre l'affichage de l'historique de conversation en cours et l'affichage uniquement de la dernière sortie de type champ ?#

Answer

A — output_mode bascule entre le rendu "transcript" (par défaut) et "field".

Q8Multiple choice

Que permet chat_input_bar(session, accept_file=True) ?#

Answer

B — accept_file=True (ou "multiple") active la pièce jointe de fichiers, enregistrée via les fonctions d'aide au téléversement dans le cwd de la session.

Q9Multiple choice

Lequel de ces éléments est un véritable paramètre de copilot_rail() ?#

Answer

A — example_questions est un paramètre documenté de copilot_rail() ; les trois autres ne font pas partie de sa signature.

Q10Multiple choice

À quoi sert job= dans copilot_rail() ?#

Answer

B — job= prend un dict (prompt, label, status, expect_structured) qui met en file d'attente un prompt à envoyer par le rail.

Q11Multiple choice

Qu'ajoute transcript_display_config() à une interface basée sur le rail ?#

Answer

A — transcript_display_config() affiche la popover des paramètres d'affichage avec les contrôles Last-messages/First-n-characters.

Q12Multiple choice

Vers quoi app_dir doit-il pointer pour que app_viewer() fonctionne correctement ?#

Answer

B — app_viewer(app_dir, ...) nécessite un dossier contenant streamlit_app.py (ou la surcharge script_name) ; il ne doit jamais pointer vers le répertoire propre de l'application hôte.

Q13Multiple choice

Que fait le bouton « Fix with CoCo » dans app_viewer() par défaut ?#

Answer

B — L'action Fix appelle on_fix avec un prompt issu de default_fix_prompt(traceback, app_dir), mettant normalement en file d'attente un job CoCo.

Q14Multiple choice

Combien de prévisualisations app_viewer() sont censées pointer vers le même app_dir en même temps ?#

Answer

B — La limitation documentée est une seule prévisualisation par app_dir.

Q15Multiple choice

Quel champ de CocoOptions contrôle la durée pendant laquelle l'application attend une décision humaine sur une approbation en attente avant de lever une erreur ?#

Answer

B — approval_timeout_seconds (valeur par défaut 600.0, soit 10 minutes) régit l'attente human-in-the-loop avant ApprovalTimeoutError.

Q16Multiple choice

Quelle est la valeur par défaut de CocoOptions.permission_mode ?#

Answer

C — CocoOptions.permission_mode a pour valeur par défaut "default" ; "plan" est utilisé explicitement pour les flux ExitPlanMode.

Q17Multiple choice

Quelle fonction sonde l'environnement (installation du SDK, accessibilité du CLI, configuration Snowflake) sans démarrer d'agent, et ne lève jamais d'exception ?#

Answer

B — check_environment() est la sonde qui ne lève jamais d'exception ; require_environment() lève des erreurs typées à la place.

Q18Multiple choice

Si toml_file n'est pas transmis et qu'il existe exactement un fichier *.toml sous ~/.snowflake/, que se passe-t-il ?#

Answer

B — Lorsqu'il n'existe qu'un seul *.toml sous ~/.snowflake/, il est utilisé quel que soit son nom de fichier.

Q19Multiple choice

Avec plusieurs fichiers *.toml sous ~/.snowflake/ et sans toml_file fourni, quel est l'ordre de sélection ?#

Answer

B — Avec plusieurs fichiers, connections.toml l'emporte en premier, puis config.toml, puis l'ordre alphabétique.

Q20Multiple choice

Que démontre examples/structured_output.py ?#

Answer

A — structured_output.py montre output_schema + on_structured_output acheminant le JSON vers un widget plutôt que vers le texte du chat.

Q21Multiple choice

Que démontre examples/headless_pipeline.py ?#

Answer

B — headless_pipeline.py est du Python asynchrone pur utilisant query()/CocoSession, sans import de Streamlit.

Q22Multiple choice

Quel type de démo est examples/approval_gate.py ?#

Answer

C — approval_gate.py démontre le composant hérité CCv2 chat() tout-en-un.

Q23Multiple choice

Qu'est-ce qui distingue examples/backlog_desk/ des autres applications d'exemple ?#

Answer

A — backlog_desk est le premier exemple basé sur le rail, sans SQL, soutenu par des fichiers JSON locaux.

Q24Multiple choice

Dans examples/backlog_desk/, comment son Copilot est-il ouvert ?#

Answer

C — Son Copilot s'ouvre depuis un bouton d'en-tête « Copilot » ou un lien d'action, et se ferme avec « Close » — ce n'est pas une page de navigation.

Q25Multiple choice

Quels types de fichiers sources examples/bi_to_semantic/ lit-il en entrée ?#

Answer

B — bi_to_semantic lit des classeurs Tableau .twb/.twbx et/ou Power BI .pbix/.pbit.

Q26Multiple choice

Où atterrissent par défaut les fichiers téléversés via upload_to_cwd() / cwd_uploader() / chat_input_bar(accept_file=...) ?#

Answer

A — Les fonctions d'aide au téléversement écrivent par défaut dans <CocoOptions.cwd>/_uploads/ (nom du sous-répertoire configurable).

Q27Multiple choice

Que l'étape « Build » de l'App Builder écrit-elle dans examples/app_builder/out/<slug>/ ?#

Answer

B — L'étape Build écrit brief.json, BRIEF.md, sketches/*, et streamlit_app.py dans out/<slug>/.

Q28Multiple choice

Où le SBOM de la version release est-il publié ?#

Answer

B — Le SBOM (CycloneDX) est attaché aux assets de GitHub Release et n'est produit qu'en CI, lors d'une release taggée.

Q29Multiple choice

Que présente render_approvals(), et dans quel ordre de boutons ?#

Answer

B — render_approvals() ordonne ses contrôles Approve once, Always allow, Deny.

Q30Select all that apply

Lesquelles de ces familles d'outils n'exposent jamais d'option « Always allow » dans l'interface d'approbation ? (Choix multiple — sélectionnez toutes les réponses applicables)#

Answer
