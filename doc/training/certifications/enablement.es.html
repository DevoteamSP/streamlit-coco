Q1Multiple choice

¿Qué problema resuelve streamlit-coco para quien escribe una app Streamlit?#

Answer

B — La librería proporciona estado de sesión, streaming de transcripción, tarjetas de herramienta y plomería de aprobación como funciones componibles, para que quien escribe la app se ocupe de la página y las opciones, no del puente de sesión.

Q2Multiple choice

¿Qué afirmación describe mejor panel()?#

Answer

B — panel(session, kwargs) -> CocoChatResult es el primitivo nativo de salida de transcripción/campo con aprobaciones y un control Stop.

Q3Multiple choice

¿Qué añade copilot_rail() sobre panel()?#

Answer

A — copilot_rail() compone panel() en un Copilot en rail lateral derecho con un selector de conexión, trabajos encolados, configuración de visualización de la transcripción y preguntas de ejemplo.

Q4Multiple choice

¿Qué hace app_viewer()?#

Answer

B — app_viewer(app_dir, ...) lanza un proceso hijo streamlit run, lo incrusta en un iframe y ofrece Fix with CoCo raspando el log de la vista previa.

Q5Multiple choice

¿Qué comando lanza la implementación de referencia de primera parte del patrón preferido (panel() + chat_input_bar())?#

Answer

B — El Makefile mapea chat a Run examples/chat_app.py; demo, run-app y copilot no son objetivos del Makefile.

Q6Multiple choice

¿Qué conjunto de prerrequisitos es correcto para empezar la ruta de Enablement?#

Answer

A — Los prerrequisitos son Python 3.10+, una cuenta de Snowflake habilitada para Cortex Code, el CLI cortex en PATH (o CORTEX_CODE_CLI_PATH), y un connections.toml/config.toml funcional — no se requiere warehouse dedicado, Docker ni manifiesto de Native App.

Q7Select all that apply

¿Cuáles de estos forman parte del pipeline del patrón preferido demostrado en examples/chat_app.py? (Opción múltiple — selecciona todas las que apliquen)#

Answer

A, B, C, D, E — A, B, C, D, E

Q8Multiple choice

¿Qué comando instala streamlit-coco para alguien que solo necesita el paquete publicado, sin un checkout del repositorio de desarrollo?#

Answer

A — La ruta que solo requiere el paquete publicado es pip install "streamlit-coco[sdk]"; make install apunta a un checkout del repositorio, y los otros dos comandos no instalan este paquete.

Q9Multiple choice

¿Bajo qué licencia se publica streamlit-coco?#

Answer

B — streamlit-coco se publica bajo Apache-2.0.

Q10Multiple choice

¿Cuál es la versión actual del paquete y el estado de lanzamiento que describe este pack de entrenamiento?#

Answer

B — El pack describe la versión 0.1.9, indicada como alpha — la API todavía puede cambiar.
