## Capture tips

- Use a **fresh** session; hide personal connection names if sensitive
- Light theme unless dark is the product default you want to brand
- Crop to the feature; avoid huge empty sidebar
- Same window width across a carousel (~1280px app width works well)
- Overlay text only in a separate marketing export — keep repo PNGs clean
